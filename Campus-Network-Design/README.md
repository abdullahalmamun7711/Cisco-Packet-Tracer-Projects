# 🎓 Campus Network Design using Cisco Packet Tracer

## 📌 Project Overview

This project demonstrates the design and implementation of a campus network using Cisco Packet Tracer. The network is divided into multiple departments using VLANs, with Inter-VLAN Routing provided by a Layer 3 Switch. There is a main campus and a branch campus of this campus. On the main campus, there is a cloud server as well. 

---

## 🎯 Objectives

* Design a hierarchical campus network
* Implement VLAN segmentation
* Configure Inter-VLAN Routing
* Configure RIPv2 routing
* Verify end-to-end connectivity

---

## 🛠 Technologies Used
